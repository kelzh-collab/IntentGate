## 签名后只走这组真机流程

1. **验签、首次安装与冷启动。** 在未安装 `com.intentgate.app` 的独立真机上验证包名、版本、证书指纹和 APK SHA-256，安装后冷启动并进入 Home。只有已有安装与正式包签名兼容、版本允许更新时才做保留数据的覆盖安装。现有 Debug 安装保留在原机。见 [安装与签名说明](INSTALLATION.md)。
2. **检查权限入口。** 先确认未授权时有明确提示，再从应用正常入口授予 Usage Access、通知和后台提醒路径需要的无障碍或悬浮权限。记录 Android 版本、ROM 和实际授权状态。
3. **两段短会话覆盖关键交互。** 添加一个可启动应用、启用管理并设置独立限额。从 IntentGate 打开该应用并通过 Intent Check 开始短会话。保持目标应用前台，等到期全屏悬浮窗出现并能交互。第一次点 Continue，确认生成新会话且旧历史保留。第二次点 Finish，确认结束、窗口关闭及 Home 剩余时间更新。在启用无障碍窗口服务的路径中，确认 Finish 直接返回桌面。仅授予悬浮权限时，按应用提示检查手动返回桌面的回退。若发版包含通知回退路径，在悬浮能力不可用时单独做一次短会话，确认通知入口可用。
4. **核对实际 Stats 日期。** 用刚产生的用量选择当天、再选另一个有效日期并返回本周。核对日期、用量、会话和查看更多，确认没有闪退或旧数据串入。其余已覆盖的语言和筛选组合无需完整重跑。

记录机型、Android API、版本、APK SHA-256、证书指纹、权限状态和每步结果。无同签名旧包时，将覆盖安装记为不适用。
